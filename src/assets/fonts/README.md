# Fonts

Drop the **Climate Crisis** font file here as:

- `ClimateCrisis-Regular.ttf`

It's loaded by `src/styles/fonts.css`. The font is variable, so a single TTF covers all weights.

If you swap to a different file (e.g. `.woff2`), update the `@font-face` rule in `src/styles/fonts.css` accordingly.
